### Inferences
- The legal risk has moved from "unknown" to "a sanctioned path exists but differs technically": SIWC uses the public Responses API, an app-registered client and plan-usage scopes, while today's code and Pi use the Codex CLI client against `chatgpt.com/backend-api/codex`. Parity measured on Codex-direct might therefore not carry over to the sanctioned endpoint. S7 should compare against the endpoint the product will actually ship on.
- Today's Codex-direct path uses `strict: false` JSON schema, so the model may already emit schema-invalid output that zod later catches. A stricter Pi tool path can only reduce invalid outputs, but it may reject schemas (for example optional `suggestedText`). S1 stays important.
- The risk "`node:sqlite` API change in v26" should be downgraded: `DatabaseSync` survives as a deprecated alias.
